开发一个公司网站

用 AI 把公司官网从需求做到页面：定信息架构、写文案、定视觉方向、生成可预览的页面，最后逐条核对事实性内容。

目标

走完「需求 → 结构 → 文案 → 页面」的完整链路，理解网站开发中哪些内容可以由 AI 生成、哪些事实必须由公司提供并确认。

操作步骤

1.
定目标与受众：网站给谁看（客户 / 求职者 / 合作伙伴）、要促成什么动作（咨询 / 留资 / 了解产品）。
2.
列信息架构：确定栏目与页面清单（首页 / 产品 / 案例 / 关于我们 / 联系），排出导航层级。
3.
备事实材料：公司简介、产品说明、资质、真实案例、联系方式——这部分必须由公司提供，AI 不生成。
4.
写文案：让 AI 按栏目逐页出文案，限定每段字数，禁止出现无法核实的表述与夸大用语。
5.
定视觉方向：给 AI 设计语言要求（主色、字体气质、版式风格），先出风格稿确认再展开。
6.
生成页面：让 AI 输出可预览的页面代码，逐个栏目生成，每页确认无误后再做下一页。
7.
事实核校：逐条核对公司名称、数据、资质、联系方式，标注所有 AI 生成但未经确认的表述。
8.
补齐常规页面：移动端适配、联系表单、页脚备案信息、404 页面。
9.
上线前检查：链接是否可用、表单能否提交、图片是否缺失。

本流程的硬性边界：禁止自动执行对外发布；网站全部事实性内容须经公司确认，AI 不得生成虚假资质、案例或客户背书。

输出结果要求

•
信息架构 1 份：栏目 + 页面清单 + 导航层级。
•
各栏目文案 1 套。
•
可预览的网站页面（首页 + 主要栏目）。
•
事实核校清单 1 份，标注待确认项。
•
上线前检查记录 1 份。

使用说明

1.
本案例是「从零做企业官网」的分步操作手册，共 9 段提示词：出方案 → 搭骨架 → 填产品数据 → 用上 Logo 与照片 → 写数据层 → 写页面渲染与样式 → 写后台管理 → 询盘写入腾讯文档 → 部署上线。
2.
每一步 = 复制提示词 → 粘贴给 WorkBuddy → 按「业务目标」操作 → 通过完成标准后再进下一步；每步都有独立代码块，逐段执行。
3.
开始前先备料：把 Logo、产品照片、产品图册、企业介绍 PPT、原官网、资质证书、案例照片、联系方式等放进项目文件夹 01-input/（原官网等可放 04-archive/），并把提示词里的 {{...}} 占位符替换成你的企业信息。
4.
全程只需要 WorkBuddy + Chrome/Edge 浏览器 + 一个腾讯云账号，不需要写代码、不需要懂技术。
5.
第 7、8 步需要腾讯文档个人 Token 与 CloudBase 环境（也可课后完成）；日常更新记住三件事：打开 admin.html → 改内容保存 → 运行 ./deploy.sh。

第 4 步｜让 AI 写数据层

业务目标：实现数据层 data.js：内嵌种子数据、提供读写 API、加入 File System 模块（选目录、恢复授权、写数据文件、存图片）与统一图片上传入口。

plain text

1. 内嵌所有种子数据（产品和分类用 data/*.js 里的内容）
