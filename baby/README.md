# 汉字小侦探 · 4 岁汉字认字量测试

给学龄前孩子测汉字认字量的可交互小游戏。**单个 HTML 文件，双击即用，断网也能玩，零依赖、零后端、零 CDN。**

> 在线试玩（GitHub Pages）：打开后即可开始，手机上可「添加到主屏幕」当 App 用。

## 玩法

屏幕中间出现一个汉字，孩子**认识就往上滑、不认识就往下滑**（电脑上左右拖），也可以直接点底部两个大按钮，或按键盘 `↑`/`↓`。

- 一局 20 张（可调 10/30/50/100），约 5 分钟
- 10 关 × 100 字，共 1000 字，按笔画从少到多递增难度
- **双模式**：孩子自评 / 家长判读（让孩子读出来，家长点对错，结果更可信）
- 积分、连击、称号、音效、朗读、复习模式、断点续玩
- 结算页：认识/不认识清单、比上次新学会的字、识字量估算、A4 复习卡打印、成绩单 CSV 导出

## 三条设计原则（改代码时请保留）

1. **积分只奖励「完成」，不奖励「认识」** —— 自评没有对错，奖励认识会诱导孩子一路乱滑刷分，数据就废了
2. **「不认识」不给负反馈** —— 没有错误音效、不用红色，图标是中性好奇脸
3. **拖拽不是唯一通道** —— 4 岁孩子手指拖拽会失败，大按钮和键盘必须保留

## 目录结构

```
index.html            成品（与 汉字小侦探.html 内容相同，供 GitHub Pages 根路径直开）
汉字小侦探.html        成品（中文名，下载到本地双击用）
使用说明.md            家长使用指南
汉字认字量测试-需求说明-v1.0.md   需求确认 + v0.1→v1.0 差异对比
src/
  base-chars.json     基础字 300（人工圈定，保证入选）
  hanzi.json          生成的 1000 字表（脚本产出，不要手改）
  app.css  app.js  index.template.html
tools/
  build-hanzi.cjs     生成字表 + QA 报告
  build-app.cjs       合并为单文件 HTML
  selftest.js         桌面端无头实测（39 项断言）
  selftest-mobile.js  手机端触摸实测（34 项断言）
  shot.js             出图做视觉验收
```

## 重新构建

```bash
node tools/build-hanzi.cjs   # 生成字表，输出 tools/hanzi-qa-report.txt
node tools/build-app.cjs     # 合并成单文件（同时写 index.html 与 汉字小侦探.html）
```

实测需要 playwright，本机 chromium 要显式指定 `executablePath`。

## 字表说明

小学低年级基础字 300（人工圈定）+ SUBTLEX-CH 真实字频榜 700（已过滤文言虚词、天干地支、音译名用字、成人向字），按「笔画数 → 字频」排序切 10 关。**不是逐字对齐某版教材**；要换成教材生字表，替换 `src/base-chars.json` 后重跑构建即可。

拼音以 `pinyin-pro` 为主源（`cnchar` 的声调数据有误，丽→lí、雨→yù 都是错的），多音字人工校准 66 字。

## 两点提醒

- **识字量是估算值**：20 张按比例外推误差偏大，想要准就一次测满一整关（100 张）
- **数据只存在浏览器本地**（localStorage），换浏览器或清缓存会丢，重要成绩记得导出 CSV
