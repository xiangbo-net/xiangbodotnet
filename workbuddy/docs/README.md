## 1. 站点概况

| 项 | 内容 |
|---|---|
| 站点定位 | WorkBuddy 企业版（SaaS 企业旗舰版 ¥198/人/月）销售专题站 |
| 线上地址 | https://xiangbo.net/workbuddy/ |
| 部署方式 | git push 到 GitHub main → Cloudflare Pages 自动部署 |
| 仓库 | https://github.com/xiangbo-net/xiangbodotnet.git（本目录为其中 workbuddy/ 子目录） |
| 技术栈 | 纯静态 HTML / CSS / JS，零构建、零依赖，直接可改可发布 |
| URL 特性 | Cloudflare Pages 会把 `.html` 308 重定向到无后缀 URL（如 /workbuddy/pricing） |

### 站点目标
- 帮客户理解产品 → 做出购买决策 → 扫码咨询（企业微信）→ 售前售后答疑。
- 全站转化动作统一收口到：**buy.html#contact 的企微扫码**（assets/wechat-contact.jpg）。

## 4. 全站统一规范（改版必读）

### 4.1 导航（五页完全一致，改一处须同步五处）
```
桌面（>900px）：[logo + 企业版] [4链接: 了解/价格与选型/落地陪跑/常见问题] [立即购买(靠最右)]
移动（≤900px）：[logo] [立即购买] [☰汉堡(最右，紧贴按钮)]
汉堡菜单展开：4 链接 + 底部蓝按钮「立即购买」（保留，勿删）
页脚「网站导航」：仅 4 个内容页链接（无立即购买）
```
- 每页 nav-links 与 .mobile-menu 内 4 链接顺序/active 高亮必须一致；改版后用脚本核对。

### 4.2 按钮文案口径
| 场景 | 固定文案 |
|---|---|
| 导航右上 / 汉堡底部 | 立即购买 / 立即咨询购买 |
| 内容区咨询 CTA | **立即咨询购买**（统一，不得出现"按此方案咨询购买/扫码沟通购买方案/咨询陪跑方案"等变体） |
| buy 页右上 | 立即咨询购买 → #contact |

### 4.3 视觉设计规范
- **配色**：主蓝 `--brand:#2160F0`（hover #1442c4）、强调绿 `#00B894`、金黄 `#FF9F1C`；深蓝横幅渐变（.hero-stage/.cta-band/.price-hero 用 #16407F→#1C4A92）。
- **按钮纪律**：深蓝底上**只放白色按钮**，永远不要绿色按钮。
- **卡片**：白底、1px var(--line) 边、圆角 16-24px、顶部 4px 色条（蓝/绿/金循环）。
- **首列强调**：对比表首列浅蓝底 #e8f1fd（表头）/#eef4fd（表体）+ 深蓝加粗字。
- **logo**：只用官方图形（wb-logo.svg），旁配「企业版」小字；不用 WorkBuddy 文字标。
- 字体栈系统默认；正文 14-16px、行高 ≥1.7；禁止粉彩/低对比配色。

### 4.4 移动端规范（≤900px / ≤600px / ≤380px 三档）
- 导航：nav-links 隐藏，汉堡抽屉菜单（.mobile-menu，fixed 顶部滑下，display:none 默认 + .open 展开）。
- **横向滑动卡片**：带 `m-hscroll` 类的网格在 ≤600px 变横滑（scroll-snap 吸附、卡片 78vw、隐藏滚动条、露边提示可滑）。适用：hero 三块/四痛点/六能力/角色/场景/指标条/采购步骤/准备卡/六项交付/ongoing 六指标。
- 表格：外层 .m-table-scroll 横滑 + min-width:680px + 首列 sticky。
- 深蓝横幅 CTA：手机端同样全宽、按钮居中。
- 禁止：页面横向溢出（html/body overflow-x:hidden）、悬浮咨询条（≤900px 隐藏 contact-dock）。

### 4.5 页脚（五页一致）
- 4 栏：品牌简介 / 网站导航（4 内容页）/ 官方资料（产品官网+两篇官方文档）/ 购买咨询（扫码沟通+查看套件对比）。
- **重要声明**（必须保留）：
  1. 本网站不属于 WorkBuddy 官方／腾讯公司。本站由腾讯云授权合作伙伴为推广 WorkBuddy 而建立。
  2. 本网站仅供购买 WorkBuddy 及相关服务时参考。WorkBuddy 的销售价格、包含权益与产品能力以 WorkBuddy / 腾讯云官方最新页面和正式合同为准。

## 5. 内容红线（不得出现）

- ❌ 个人版 / 私有化 / VPC 版的价格或选型内容（只销售 SaaS 企业旗舰版 ¥198）
- ❌ 「励拓咨询」「授权伙伴」「陪跑」等字样出现在页面文案（落地陪跑页只称「服务方」）
- ❌ 芯恩等具体客户案例、内部销售话术（电销脚本等）
- ❌ 「少量账号」「2-3 岗位」「3-5 账号」等具体起步数字（统一用「数个岗位/席位」）
- ❌ CSS 内联营销像素、第三方统计脚本
- ⚠️ 价格与权益标注为时点信息，以官方页面/合同为准

## 6. CSS 结构说明（style.css）

- 单文件约 1000 行，**分层追加式**演化（基础 → 视觉升级 → 移动端修复 → 区块定制）。规则多用 `!important` 保证后定义优先——**改动时优先在文件末尾追加新块，勿轻易删改中段**。
- 关键断点：1080（套件网格）/ **960（nav-links 隐藏分界）**/ 900（移动导航+汉堡）/ 640（横幅/套件卡压缩）/ 600（横滑卡片+页面压缩）/ 380（极限压缩）。
- 核心组件类：`.btn`（primary/ghost/lg）、`.card`（.num 序号+色条）、`.case`、`.metric`、`.cta-band`（深蓝横幅）、`.source-red`（浅红提示框）、`.m-hscroll`（移动横滑）、`.m-table-scroll`（表格横滑）、`.mobile-menu`、`.contact-dock`（右侧竖条咨询）。
- **改版验证流程**：改前/改后各截 5 页 × 3 宽度（1280/930/500）截图做像素对比（PIL ImageChops），确保无意外回归。

## 7. 改版/修订标准流程

1. **本地起服务**：`cd workbuddy && python3 -m http.server 8894`，访问 http://127.0.0.1:8894/。
2. **修改**：改 HTML 直接编辑；改样式在 style.css 末尾追加；新页面复制现有页面骨架（nav/footer/menu 三件套）。
3. **自检脚本要点**（Python）：
   - 标签配平（div/section 开闭数相等）
   - 全部 href/src 本地引用存在性、页内锚点存在性
   - 导航/菜单/页脚五页一致性 diff
   - 渲染截图：`"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --window-size=1280,900 --screenshot=out.png URL`（headless 最小视口约 500px，测手机用 CDP Emulation）
4. **提交**：`git add -A && git commit -m "..." && git push origin main`。
5. **线上验收**：等 1-2 分钟后访问 https://xiangbo.net/workbuddy/ 逐页核对（注意 Cloudflare 308 去 .html）。
